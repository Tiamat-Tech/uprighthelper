Welcome to the Upright Helper.


To have a proper posture, you need to stay upright while sitting. This website is designed to help you achieve this by warning you whenever you are not sitting upright.


To use this site effectively, all you have to do is:

  • 1.When asked by the browser, give permission to utilize the webcam.
  • 2.Sit in a proper position (upright) and click the Right Posture button a few times. (15-20 is usually enough). Each time you press the button it captures frames and calibrates your upright baseline.
  • 3.Next, sit in a wrong position, (NOT upright) and click the Wrong Posture button a few times. (15-20 is usually enough).
  • 4.After doing all these steps, you are ready to go. Leave the website open and it will warn you with sound/visuals whenever you start sitting in a wrong position.
  • 5.If you think it is not working accurately enough, try adding more right/wrong posture samples.

Note that, this website does not send any data to the web. Everything happens locally, which means YOUR data stays at YOUR machine. Calibration is saved in your browser.
